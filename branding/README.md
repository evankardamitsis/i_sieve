# i‑sieve branding kit

Colours
- Blue (primary)  #1f3fbf
- Coral (signal)  #d9583b
- Ink             #141412
- Paper           #f4f1ea

Typeface: Figtree SemiBold (wordmark, converted to outlines). 

Files
- isieve-mark-{blue,ink,paper}      — the perforated-disc mark, transparent background
- isieve-icon-{blue,ink}-tile       — 1024px app icon / social avatar
- isieve-logo-horizontal-light(-bg) — mark + wordmark for light backgrounds (with/without paper bg)
- isieve-logo-horizontal-dark(-bg)  — for dark backgrounds
- isieve-logo-horizontal-mono-*     — single-colour versions
- isieve-wordmark-{blue,ink,paper}  — wordmark only

Clear space: keep at least the height of the mark's signal dot ×4 around the logo.
Minimum size: mark 16px; horizontal logo 100px wide.
